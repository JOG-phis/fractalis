### Dos ejercicios para empezar

{{< ejercicio n="3" pista="Orden: metales, otros no metales, H y O. Si te sale un decimal, multiplica todo por 2." solucion="a) \(\ce{2H2 + O2 -> 2H2O}\). b) \(\ce{N2 + 3H2 -> 2NH3}\). c) \(\ce{2Na + Cl2 -> 2NaCl}\). d) \(\ce{2Mg + O2 -> 2MgO}\). e) \(\ce{2KClO3 -> 2KCl + 3O2}\). f) \(\ce{4Al + 3O2 -> 2Al2O3}\)." >}}
Ajusta estas ecuaciones químicas: a) \(\ce{H2 + O2 -> H2O}\); b) \(\ce{N2 + H2 -> NH3}\); c) \(\ce{Na + Cl2 -> NaCl}\); d) \(\ce{Mg + O2 -> MgO}\); e) \(\ce{KClO3 -> KCl + O2}\); f) \(\ce{Al + O2 -> Al2O3}\).
{{< /ejercicio >}}

{{< ejercicio n="23" pista="Ajusta primero. Por cada 2 mol de Mg reacciona 1 mol de \(\ce{O2}\)." solucion="a) \(\ce{2Mg + O2 -> 2MgO}\). 12 g de Mg son 0,5 mol. b) 0,25 mol de \(\ce{O2}\): 8 g. c) 0,5 mol de MgO: 20 g. d) \(12 + 8 = 20\) g." >}}
El magnesio arde con una luz blanca muy intensa: \(\ce{Mg + O2 -> MgO}\). Se queman 12 g de magnesio. a) Ajusta la ecuación. b) ¿Qué masa de oxígeno reacciona? c) ¿Qué masa de óxido de magnesio se forma? d) Comprueba la ley de Lavoisier.
{{< /ejercicio >}}
