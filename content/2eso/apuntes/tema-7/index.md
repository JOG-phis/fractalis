## 1. La energía

{{< caja idea "Energía:" >}}
es la capacidad de los cuerpos para **producir cambios**.
{{< /caja >}}

- Se **transforma**, se **transfiere**, se **almacena** y se **transporta**.
- Se **conserva**: no se crea ni se destruye, solo se transforma.
- Se **degrada**: en cada transformación, parte se convierte en calor que no se aprovecha.

### Las unidades de energía

La unidad del Sistema Internacional es el **julio** (J).

| Equivalencias |
| :---: |
| \(1\,\text{kJ} = 1000\,\text{J}\) |
| \(1\,\text{cal} = 4{,}18\,\text{J}\) |
| \(1\,\text{kcal} = 1000\,\text{cal}\) |
| \(1\,\text{kWh} = 3\,600\,000\,\text{J}\) |

Para cambiar de unidad usamos **factores de conversión**:

{{< formula >}}2\,\text{kcal} \cdot \frac{1000\,\text{cal}}{1\,\text{kcal}} \cdot \frac{4{,}18\,\text{J}}{1\,\text{cal}} = 8360\,\text{J}{{< /formula >}}

## 2. Las fuentes de energía *(energy sources)*

| | Cuáles son | Características |
| :--- | :--- | :--- |
| **No renovables** *(non-renewable)* | carbón, petróleo y gas natural (combustibles fósiles) y uranio (nuclear) | Se agotan. Contaminan (\(\mathrm{CO_2}\), residuos radiactivos). Siempre disponibles. |

## 3. La temperatura y el calor

{{< caja idea "Temperatura:" >}}
indica lo caliente o frío que está un cuerpo: cuanto más deprisa se mueven sus partículas, mayor es. Se mide con el **termómetro**.
{{< /caja >}}

{{< figura src="temperatura.svg" alt="Partículas que se mueven despacio a baja temperatura y deprisa a alta temperatura" ancho="460" >}}

- Escalas: **Celsius** (°C) y **Kelvin** (K, la del Sistema Internacional).
- **Cero absoluto:** 0 K = −273 °C. No hay temperaturas negativas en kelvin.

{{< formula >}}T\,(\text{K}) = T\,(^\circ\text{C}) + 273{{< /formula >}}

{{< caja idea "Calor:" >}}
es la energía que pasa de un cuerpo a otro que está a **distinta temperatura**, siempre del más caliente al más frío. Se mide en J (o en cal).
{{< /caja >}}

{{< figura src="equilibrio-termico.svg" alt="Un cuerpo a 80 °C y otro a 20 °C en contacto acaban los dos a 50 °C" pie="Al final, los dos cuerpos llegan a la misma temperatura: el **equilibrio térmico**." ancho="460" >}}

{{< caja cuidado >}}
los cuerpos **no tienen** calor: tienen temperatura y **ceden** o **absorben** calor.
{{< /caja >}}

## 4. Los efectos del calor

| Efecto | Qué ocurre |
| :--- | :--- |
| **Cambio de temperatura** | Al absorber calor, el cuerpo se calienta; al cederlo, se enfría. Depende de la masa y del material. |
| **Dilatación** | Al calentarse, los cuerpos aumentan de tamaño; al enfriarse, se contraen. Los gases son los que más se dilatan. |
| **Cambio de estado** | Progresivos (absorben calor): fusión, vaporización y sublimación. Regresivos (ceden calor): solidificación, condensación y sublimación inversa. Durante el cambio, la temperatura no varía. |
