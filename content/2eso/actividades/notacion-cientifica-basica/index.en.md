{{< lead >}}
An introductory scientific notation worksheet for numbers with **a single non-zero digit**: you just need to count the zeros.
{{< /lead >}}

{{< caja nota "How do you do it?" >}}
1. Write the digit that is not zero.
2. Count the zeros.
3. That number goes up top, on the 10.
4. If the zeros are in front (it starts with 0.), add a minus sign.
{{< /caja >}}
